# 早押しクイズ（かんたん版）

`index.html` を1つ置くだけで使える早押しクイズです。アカウント登録や設定ファイルは要りません。参加者は QR コードを読み取り、名前を入れるだけでスマホから回答できます。

## 公開のしかた（GitHub Pages・約5分）

1. GitHub で新しいリポジトリを作ります（Public）。
2. 「Add file → Upload files」から `index.html` をアップロードします。
3. 「Settings → Pages」を開き、Branch を `main` / `(root)` にして Save します。
4. 1〜2分後に表示される URL（`https://ユーザー名.github.io/リポジトリ名/`）が完成です。

## 参加用URLが開けないとき

- **司会画面は、必ず公開したURL（`https://ユーザー名.github.io/…/?host`）から開いてください。** パソコンに保存した HTML をダブルクリックして開くと、QRコードのURLがそのパソコンの中を指してしまい、スマホからは開けません。この場合は司会画面に赤い注意が出るので、公開URLを入れれば QR コードが作り直されます。
- `github.com/…/blob/…` の URL はファイルの中身を表示する画面です。Settings → Pages に表示される `github.io` の URL を使ってください。
- リポジトリは Public にしてください（無料プランでは Private のリポジトリは公開されません）。
- 「サーバーに接続できません」と出る場合は、会社の Wi-Fi が中継サーバーを止めている可能性があります。モバイル回線で開くか、司会画面の「別の中継サーバーに切り替える」を押して QR コードを配り直してください。

## 当日の使い方

1. **司会PC** で URL を開き、「司会として始める」を押します。
2. 「参加者名簿」に名前を貼り付けて「名簿に追加」を押します。
3. 「モニターを全画面で表示」を押してプロジェクターに映すと、参加用の QR コードが大きく出ます。
4. 参加者は QR を読み取り、名簿の名前を入れて「参加する」を押します。
5. 問題を入れて「出題する」を押します。時間が来たら正解の色を押すと、最速正解者とランキングが出ます。

**サブ司会（2人目）** は、司会画面にある「サブ司会用URL」を開き、PIN（4桁）を入れると出題や発表を操作できます。同じURLは、別PCのモニター表示にも使えます。

## 大切な注意

- **司会PCのタブが進行の中心です。** 名簿・得点・回答はこのブラウザに保存されます。途中で閉じたり再読み込みしても続きから再開できますが、クイズ中は開いたままにしてください。PCのスリープも切っておきましょう。
- **通信の中継に、無料の公開サーバーを使っています。** 普段は HiveMQ、つながらないときは司会の URL を `?host&b=1` にすると EMQX に切り替わります。切り替えたら QR コードを配り直してください。
- **社内イベントなどの気軽な用途向けです。** 公開サーバーのため、ルームコードを知っている人は通信内容を見られる可能性があります。個人情報や機密は問題文に入れないでください。
- **本番前に試しておきましょう。** スマホ2〜3台で通しテストをしておくと安心です。会社の Wi-Fi で公開サーバーへの接続が止められている場合は、モバイル回線で参加してもらってください。
